## 🧠 Описание проекта

**Tic-Tac-Toe (крестики-нолики)** — простая пошаговая логическая игра для двух игроков, в которой они по очереди заполняют клетки 3×3, стремясь выстроить линию из трёх собственных символов (крестиков или ноликов).  

Проект реализует:

- игровое поле 3×3;
- проверку победы;
- переключение между игроками;
- отображение текущего состояния игры (ход игрока, победитель, ничья и т.д.);
- уведомления об первом ходу и результате игры;
- анимацию победы.
